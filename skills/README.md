# Навыки департамента

Навык (Agent Skill) — это папка с `SKILL.md`, которую агент подхватывает сам:
Claude Code читает `~/.claude/skills` и `.claude/skills` проекта, Codex —
`~/.codex/skills`, `~/.agents/skills` и `.agents/skills` проекта.

Департамент держит навыки **у себя**, а не ссылается на них. Внешний
репозиторий может исчезнуть, переехать, сменить условия или молча поменять
содержимое — на работе BXE это не должно отражаться никак. Поэтому взятое
берётся целиком, вместе с лицензией и отпечатками, а целость копии держит суд.

| папка | что это |
|---|---|
| `loop-code-review/` | дословная копия первоисточника (MIT, Dima Sukharev). Не правится. Происхождение и отпечатки — в `ORIGIN.md` |
| `loop-code-review-bxe/` | редакция департамента: та же петля, но с гейтом департамента вместо «подходящих проверок» и с машинной таблицей приёмки (`bin/loop.py`, ст. 58) |

## Поставить агенту

```bash
# Claude Code, глобально
mkdir -p ~/.claude/skills
cp -R skills/loop-code-review-bxe ~/.claude/skills/

# Codex CLI
mkdir -p ~/.codex/skills
cp -R skills/loop-code-review-bxe ~/.codex/skills/

# только этому проекту
mkdir -p .claude/skills && cp -R <BXE>/skills/loop-code-review-bxe .claude/skills/
```

`install.sh` департамента делает это сам, если находит каталог агента.

Обе редакции ставить не нужно: они описывают одну петлю. Дословная лежит
здесь ради предъявляемого происхождения, работать нужно редакцией
департамента — у неё измеримое условие выхода.

## Проверить

```bash
python3 bin/loop.py --court     # суд органа: 32 проверки в обе стороны
```

Суд валится, если дословная копия изменилась без правки `ORIGIN.md`.
Происхождение — документ, а не обещание.
