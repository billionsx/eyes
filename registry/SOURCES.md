# ХРАНИМОЕ И ВЫВОДИМОЕ

У департамента два рода файлов, и путать их дорого.

## Хранимое — потеряешь, не восстановишь

| что | откуда | кто держит |
|---|---|---|
| `registry/corpus/hig/` | машинный JSON страниц Apple | жатва (`bin/harvest.py`) |
| `registry/library/*.jsonl` | законы: свод и таблицы | атлас и жатва |
| `registry/standards/tokens.json` | **ЗАМЕР** — снято с кадров iOS | конвейер геометрии |
| `registry/standards/symbols/` | имена глифов из `SF Symbols.app` | macOS-плечо |
| `registry/fixtures/apple/` | образцы JSON для суда офлайн | разовый зонд |

## Выводимое — пересобирается за секунду

| что | из чего | чем |
|---|---|---|
| `registry/standards/palette.json` | законы образцов цвета | `bin/palette.py` |
| `registry/standards/typescale.json` | таблицы типографики | `bin/typescale.py` |
| `registry/standards/devices.json` | таблицы устройств | `bin/devices.py` |

Всё выводимое собирается одной командой:

```bash
python3 bin/rebuild.py           # пересобрать
python3 bin/rebuild.py --check   # снос: расходится ли с источником
```

## Почему это разведение важно

**Конфликт выводимого не сливают, а пересобирают.** Своей истины у свода
нет — вся истина в источнике. Ежедневный работник переписывает своды каждым
прогоном, и склеивать их построчно с чужой правкой бессмысленно: результат
не будет соответствовать ни одной стороне. Поэтому в `.gitattributes` они
объявлены `merge=ours`, а контур после слияния пересобирает их заново.

**Правка выводимого руками — тихая порча.** Она переживёт один прогон и
умрёт на следующем, а между ними департамент будет судить по числу,
которого нет в источнике. `--check` ловит такую правку и восстанавливает
файл из источника.

**Выводимое всё равно лежит в репозитории.** Клиент ставит департамент
клоном и запускает MCP-сервер локально, без всякого CI: если сводов в
клоне не будет, светлая тема и шкала молча отключатся. Хранение здесь —
не дублирование истины, а доставка.
