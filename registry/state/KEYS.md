# ДОЗОР СРОКОВ

Сроки, после которых департамент останавливается целиком. Оба рода
отказа приходят в назначенный день сразу и оба выглядят как
поломка департамента — поэтому дни считаются на каждом прогоне.

Столбец «род» важен: ЗАМЕР снят с источника заголовком, ОБЪЯВЛЕНО
взято из предупреждения и проверяется по адресу. Это сведения
разной прочности, и смешивать их нельзя (ЗКН-Э001).

Ключей департамент не выписывает: у GitHub нет API для выдачи
ключей, и это правильно — инструмент, способный выписать себе
доступ, есть дыра. Орган считает дни и называет их вслух.

**Ближайший срок: 31 дней.**

- **ключ забора кода клиентов** — снято заголовком источника
- **ключ прогона** — ключа GITHUB_TOKEN у органа нет — измерить нечего. Молчание не есть исправность (ЗКН-Э001)
- **двухфакторная защита аккаунта billionsx** — объявлено 2026-08-05 по источнику: предупреждение GitHub в интерфейсе аккаунта · сверить: https://github.com/settings/security
