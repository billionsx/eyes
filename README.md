**Автономный департамент стандартов Apple.** Живёт в своём репозитории, не
принадлежит ни одному проекту и подключается к любому — паспортом.

Эфир: **[vrajs.com](https://vrajs.com)** · лист в Markdown:
[`dashboard/DASHBOARD.md`](dashboard/DASHBOARD.md) · устав:
[`CONSTITUTION.md`](CONSTITUTION.md) редакция 8.

Органы: **разведка** официальных источников Apple без ИИ · **атлас** всей
документации · **библиотека** законов с адресом каждого числа · **знание**
(нормативные выжимки) · **кит** (величины официальных design kit) ·
**кадротека** (кадры приложений Apple) · **живой взгляд** (настоящий DOM
и computed-styles прода) · **советник и храповик** (долг только падает) ·
**петля ревью** (круг «свежий ревьюер → правки → проверка» до подписи,
ст. 58) · **суд** (selftest на живых нарушениях в обе стороны) · **дозор iOS 27**
с протоколом смены базы · **служба** (ревью PR, монитор прода,
пиксель-сертификация, страж App Store, Big7-бриф).

Только stdlib Python 3 — ни одной зависимости в ядре.

## Подключить любой проект

```bash
python3 bin/eyes.py attach --project мойпроект \
    --repo billionsx/мойрепо \
    --prod https://мойдомен.com \
    --globs "src/**/*.css,src/**/*.tsx"
python3 bin/eyes.py projects          # проверить реестр
```

Появится паспорт `adapters/мойпроект.json` — департамент сам заберёт код
в `_projects/`, пройдёт советником и прибьёт долг храповиком (ст. 57).

Со стороны проекта — два необязательных файла из [`templates/`](templates/):

| файл | что даёт |
|---|---|
| `eyes-client.yml` | построчное ревью каждого PR законами департамента |
| `ping-eyes.yml` | монитор смотрит на прод сразу после деплоя |

Порядок принуждения: новый проект всегда начинает в режиме `report`
(советник); правило переводится в `strict`, когда его долг равен нулю.

## Команды

```
python3 bin/eyes.py status      # сводка департамента
python3 bin/eyes.py selftest    # суд: ломаю → красный, чиню → зелёный
python3 bin/eyes.py loop start --root . --paths "src/a.css"   # петля ревью
python3 bin/eyes.py projects    # реестр подключённых проектов
python3 bin/eyes.py crawl       # разведка (живая сеть)
python3 bin/eyes.py atlas       # шаг по документации
python3 bin/eyes.py ios27       # дозор новой базы
python3 bin/eyes.py digest      # знание из снимков
python3 bin/eyes.py verify      # сверка конституция ↔ реестр ↔ знание
python3 bin/eyes.py study       # изученность каждой статьи кодекса
python3 bin/fetch.py            # забрать код подключённых проектов
python3 bin/dashboard.py        # пересобрать эфир

PROJECT_ROOT=_projects/X python3 bin/eyes.py lint --adapter X --mode report \
    --ratchet registry/state/ae-baseline.json
```

## Воркфлоу

| воркфлоу | когда | что делает |
|---|---|---|
| `eyes` | пуш · пн и чт 05:43 UTC · руками | суд → разведка → дозор iOS 27 → знание → сверка → советник и храповик по всем паспортам |
| `eyes-yield` | ежесуточно | веб-атлас · кит · большая семёрка · живой взгляд |

| `eyes-certify` | 1-го числа | пиксель-сертификат каждому проекту (HTML · PDF · бейдж) |

| `eyes-brief` | пн | Big7-бриф недели |
| `eyes-review-reusable` | вызов из репо проекта | ревью PR клиента |

## Правила дома

Ни одного числа из головы: каждое несёт адрес замера или первоисточника
(ЗКН-Э001). Каждое правило доказано живым нарушением в обе стороны, иначе
не действует (ст. 44). Пустой обход не ужимает храповик (ст. 45.1).
Хроника коммитится в репозиторий — это основной канал наблюдаемости.
