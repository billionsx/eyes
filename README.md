# BXH · Billions X Hands

Второй суверенный департамент Billions X. **Порядок в коде**: безопасность,
структура, зависимости, гигиена — автономно, для любого приложения.

**Глаза смотрят. Руки правят.** BXE (`billionsx/eyes`) надзирает за стандартами
Apple и по своей конституции писать не имеет права. BXH существует, чтобы
писать — и потому стоит на отдельном уставе с отдельным регулятором власти.

## Что здесь есть

| орган | файл | что делает |
|---|---|---|
| РАЗВЕДКА | `bin/intake.py` | суточный обход OSV · GHSA · NVD · реестров правил |
| КОДЕКС | `registry/library/laws.json` | законы серии `ЗКН-Х`, у каждого проверка и потолок |
| ГУБЕРНАТОР | `bin/governor.py` | присваивает находке класс автономии К0–К3 |
| ИНВАРИАНТЫ | `bin/invariants.py` | форма приложения до и после правки |
| СУД | `bin/hands.py selftest` | каждая способность доказана в обе стороны |

## Классы автономии

- **К0 · АВТОМАТ** — доказуемо сохраняет семантику, обратимо. Пишет сам.
- **К1 · АВТОМАТ ПОД ПРОТОКОЛОМ** — в ветку, с доказательством, слияние по инвариантам.
- **К2 · ПРЕДЛОЖЕНИЕ** — не исполняется никогда. Дифф как инструкция.
- **К3 · ЗАПРЕТ РУКИ** — доступ, платежи, схема, секреты, удаление. Только доклад.

Строжайший побеждает; понижающих правил не существует.

## Подключение

`adapters/<имя>.json` — корень, глобы, защищённые зоны, инварианты, радиус,
окно исполнения. Больше клиент нигде не упоминается.

```
python3 bin/hands.py selftest
python3 bin/hands.py classify <паспорт> <закон> <путь>
python3 bin/hands.py snap <корень> adapters/<имя>.json
```

Устав — `CONSTITUTION.md`. При расхождении инструмента с уставом прав устав.
