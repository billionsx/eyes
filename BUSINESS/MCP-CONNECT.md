# ПРИСУТСТВИЕ · подключение департамента к редактору

Департамент до сих пор судил после факта: гейт ловит написанное, монитор —
отгруженное. Приговор приходил, когда нарушение уже стоило рабочего дня.
Присутствие ставит департамент рядом в момент письма.

## Что получает разработчик

Четыре инструмента прямо в агенте (Claude Code, Cursor, Windsurf, Codex):

| инструмент | что делает |
|---|---|
| `eyes_check` | судит фрагмент кода правилами AE1–AE15 — **теми же, что в CI** |
| `eyes_law` | ищет норму Apple под вопрос, отдаёт текст **и адрес страницы** |
| `eyes_token` | выдаёт измеренное число базы (снято с кадров iOS, не процитировано) |
| `eyes_attest` | показывает, подтверждён ли замер словами свода |

Один закон — одно исполнение. `eyes_check` не имеет собственных правил: он
зовёт `bin/lint.py`, тот самый орган, что стоит в гейте. Своя копия правил
внутри сервера означала бы два вердикта об одном коде и медленное расхождение
между ними — расхождение обнаружилось бы у клиента и стоило бы репутации.

## Подключение

Требуется Python 3 и ничего больше: внешних зависимостей у сервера нет.

```bash
git clone https://github.com/billionsx/eyes.git
python3 eyes/bin/mcp.py --court     # 15 зелёных строк — сервер исправен
```

В `mcp.json` клиента:

```json
{
  "mcpServers": {
    "eyes": {
      "command": "python3",
      "args": ["/абсолютный/путь/eyes/bin/mcp.py"]
    }
  }
}
```

Перезапустить редактор. Инструменты появятся в списке под именем `eyes`.

## Как это выглядит в работе

Запрос агента:

```
eyes_check { "code": ".card{background:#111;box-shadow:0 4px 12px rgba(0,0,0,.4);
              border-radius:20px;letter-spacing:1.2px;
              transition:all 400ms ease;}" }
```

Ответ — шесть находок с номерами правил и причинами:

```
AE2  свечение/тень на чёрном холсте запрещены — глубину даёт ступень поверхности
AE3  border-radius 20px > 12pt без формы суперэллипса
AE4  letter-spacing 1.2px — крышка поправки ±0.4px; роль задаётся в em
AE8  движение 400ms на дефолтной кривой — от 200ms положена измеренная
AE11 border-radius 20px вне измеренной лестницы [8, 12, 16, 24, 29, 37.8]
AE13 есть движение ≥200ms, но нет @media (prefers-reduced-motion)
```

Ни одна из шести причин не является вкусом: каждая ведёт в замер с адресом.

## Границы

Департамент **предъявляет норму, а не пишет код**. Он не чинит, не предлагает
«как лучше» и не спорит о вкусе. Решение остаётся за человеком (устав ст. 7.4).

Сервер работает локально по stdio. Код клиента никуда не уходит: сеть серверу
не нужна и он в неё не ходит.

## Журнал жизни правила

Сервер ведёт локальный журнал: какое правило сработало, когда, на каком языке
и в каком сеансе. **Ни строки кода, ни имени файла, ни причины находки** —
причина цитирует значение из вашего кода и потому запрещена. Журнал лежит в
`var/presence.jsonl` рядом с сервером и никуда не отправляется.

Проверить самому:

```bash
python3 bin/tally.py            # что накопилось
python3 bin/tally.py --digest   # агрегат, годный к отправке
python3 bin/tally.py --forget   # стереть
EYES_NO_JOURNAL=1               # не вести вовсе
```

Обещание не декларируется, а проверяется машиной: в суде сервера стоит
проверка, которая судит фрагмент с меткой «коммерческая тайна» и требует,
чтобы ни метка, ни цвет, ни текст причины в журнал не попали.

Зачем это департаменту. Правило, срабатывающее у многих, — кандидат в норму
по умолчанию. Правило, которое **работало и промолчало**, — вопрос: оно
бесполезно или работает сдерживанием. Правило, которое не включали, вопроса
не задаёт вовсе — и департамент не выдаёт его за молчание. Если пришлёте
`--digest`, департамент учтёт ваш опыт при пересмотре правил. Не пришлёте —
инструмент работает ровно так же.
