# Billions X Eyes — как пользоваться

Инструмент, который подключается к любому проекту и поднимает уровень
интерфейса, кода и бизнес-логики до нормы мировых гигантов. Не советами —
измеренными числами с адресом первоисточника.

## Установка (одна команда)

```bash
curl -fsSL https://raw.githubusercontent.com/billionsx/eyes/main/install.sh | bash
```

Скрипт поставит департамент в `~/.billionsx-eyes`, прогонит суд исправности
и напечатает готовый блок для `mcp.json`. Вставить, перезапустить редактор —
всё.

Нужны только `git` и `python3`. Никаких пакетов, зависимостей и ключей.

## Что сказать агенту

| скажи | что произойдёт |
|---|---|
| «просканируй проект через eyes» | обойдёт дерево, выдаст балл, грейд и разбор по правилам |
| «почини всё, что нашёл eyes» | у каждой находки есть ЦЕЛЬ — точное число, что поставить |
| «что Apple говорит про контраст» | норма дословно + адрес страницы |
| «есть ли системная иконка для поиска» | точное имя SF Symbol |
| «что Большая семёрка говорит про удержание клиента» | положение McKinsey/BCG/Bain и др. + адрес |

## Восемь инструментов

**`eyes_scan`** — главный. Судит **весь проект** по пути. Паспорт и настройка
не нужны: дерево обходится само, `node_modules` и сборка не берутся.
Работает с css, scss, html, ts, tsx, js, jsx, vue, svelte.

Отдаёт балл, грейд, худшие файлы и разбивку по правилам — **с целью для
каждого**:

```
AE8  ×58  Длинное движение на дефолтной кривой.
      → Поставить измеренную кривую вместо ease/linear.
      цель: motion.curve = cubic-bezier(.32,.72,0,1), от 200 ms

AE11 ×48  Радиус вне измеренной лестницы.
      → Взять ближайший радиус из лестницы.
      цель: [8, 12, 16, 24, 29, 37.8] pt
```

**`eyes_guide`** — что делать с находкой. По номеру правила: проблема,
действие, цель из замера и слова Apple с адресом, если норма подтверждена
двойным свидетельством.

**`eyes_symbol`** — есть ли у Apple системный глиф под этот смысл. 9184 имени
SF Symbols, снятые с настоящего приложения. Понимает словарь веба:
`search → magnifyingglass`, `close → xmark`, `share → square.and.arrow.up`.
Рисовать свою иконку там, где есть системная, значит разойтись с системой
на глазах у пользователя.

**`eyes_business`** — бизнес-логика Большой семёрки: Deloitte, PwC, EY, KPMG,
McKinsey, BCG, Bain. Положение фирмы дословно + адрес страницы.

**`eyes_check`** — судит фрагмент кода на лету, пока агент его пишет.

**`eyes_law`** — норма Apple под вопрос: 30 000+ норм, 336 фреймворков,
адрес страницы у каждой.

**`eyes_token`** — измеренное число базы. Не процитировано из документации —
**снято с кадров iOS**.

**`eyes_attest`** — подтверждён ли замер словами свода. `ПОДТВЕРЖДЕНО` —
число и текст Apple совпали. `ПРОТИВОРЕЧИЕ` — Apple пишет одно, отгружает
другое.

## Чем это отличается от линтеров

Линтер проверяет стиль кода. Департамент проверяет **соответствие
операционной системе**, и числа берёт не из документации, а из замера
реальных кадров iOS. Документация стареет молча — кадры нет.

Три правила стоят на **двойном свидетельстве**: число снято с кадров **и**
подтверждено словами Apple с адресом страницы. Ни один конкурент не держит
оба конца сразу.

## Приватность

Сервер работает локально по stdio. **Код никуда не уходит**: сеть серверу не
нужна, и он в неё не ходит.

Локальный журнал пишет только номера сработавших правил — ни строки кода, ни
имени файла. Выключается `EYES_NO_JOURNAL=1`, стирается
`python3 bin/tally.py --forget`.

## Проверить исправность

```bash
python3 ~/.billionsx-eyes/bin/mcp.py --court     # 27 зелёных строк
```
